Sistema Inteligente de Iluminación Circadiana y Monitoreo del Sueño (IoT + Machine Learning) 

Autores:
Ana Alvarez Ramirez
Ary Naim Moreno Garcia

Descripción del Proyecto
Sistema no invasivo de monitoreo del ciclo de sueño e iluminación circadiana adaptativa que integra Internet de las Cosas y Machine Learning 
Por la noche:
Activa una luz roja tenue de forma intermitente cerca de la hora predicha para dormir.
Por la mañana:
Simula el amanecer mediante un incremento gradual de luz cálida (rampa ajustable entre 10 y 30 min) calculada según los hábitos recientes del usuario
